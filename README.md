# Brewers App

コーヒーの抽出比率や豆の分量を算出・管理するためのWebアプリケーションです。

## 概要
コーヒー初心者のためのアプリ
ドリップコーヒーを淹れる際に必要な比率計算やストップウォッチ機能をまとめたもの

## 背景と目的
趣味としてのコーヒーを始める人はまず自宅でドリップを行う人が多い。
抽出に必要な最低限の器具と豆だけ買った後、どのように抽出するかはインターネットで様々な方法が上がっている。
どんな方法でもコーヒーを淹れるには量と時間を計ることが重要である。
比率計算もストップウォッチもスマホでできるが、コーヒーを淹れる時間を特別なものにしてほしいので専用のツールを作成した。
また、コーヒー豆の飲み頃のピークは焙煎日から2週間付近とされているため、購入したコーヒー豆と焙煎日を記録して飲み頃を教えてくれる機能も追加した。

## 機能要件
- [x] 何杯分かに応じた水の量計算
- [x] 豆の量（g）の自動計算
- [x] 抽出タイマー機能
- [ ] 豆の記録
